# Contributing to Pixi

This document is intended for anyone considering opening a **pull request**.

We are very active on our [Discord Server].
If you want quick feedback, please contact us there!

## The Critical Rules

**The most important rule: you must understand your code.**
If you can't explain what your changes do and how they interact with the greater system without the aid of AI tools, do not contribute to this project.
Be sure to read the [AI Usage Policy](AI_POLICY.md).

**Value maintainer time and effort.**
We are only humans.
We really appreciate contributions!
But we only have limited resources.
When you make a contribution you are asking us to spend time and effort on your contribution by means of review and discussion.
We love looking at high-quality contributions but requesting us to spend time and effort on low-quality contributions generated without any effort by a human is insulting.

## First-Time Contributors

We use a vouch system for first-time contributors:

1. Open a [discussion in the "Vouch Request"](<FILL ME>) category describing what you want to change and why.
   Follow the template.
2. Keep it concise
3. Write in your own voice, don't have an AI write this
4. A maintainer will comment `!vouch` if approved
5. Once approved, you can submit PRs

If you aren't vouched, any pull requests you open will be automatically closed.
This system exists because open source works on a system of trust, and AI has unfortunately made it so we can no longer trust-by-default because it makes it too trivial to generate plausible-looking but actually low-quality contributions.

## Contributors Prior to the Vouch System

If you contributed to this project prior to the introduction of the vouch system and wish to continue contributing, you were not automatically added to the [list of vouched users](.github/VOUCHED.td).
You will need to follow the same process as a first-time contributor to be vouched.

## Denouncement System

If you repeatedly break the rules of this document or repeatedly submit low quality work, you will be **denounced.**
This adds your username to a public list of bad actors who have wasted our time.
All future interactions on this project will be automatically closed by bots.

The denouncement list is public, so other projects who trust our maintainer judgement can also block you automatically.

## Opening a Pull Request

1. Make sure [you are vouched](#first-time-contributors)
2. If there's no issue yet, create one
3. Contact us via our [Discord Server] or open a GitHub discussion to signal your willingnes to work on this thing.
   One of our maintainers will let you know shortly if we are interested in you working on this issue  
4. If one of the maintainers approved your task, open a pull request
