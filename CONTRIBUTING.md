# Contributing to Pixi

We welcome contributions to Pixi in the form of discussions, issues, and pull requests! There are a few rules to follow when making contributions that are important to keep in mind.

We are very active on [our Discord Server][discord].
If you want quick feedback, please contact us there!

## The Golden Rule

**When opening issues, PRs, or discussions, include a human-written description at the start.**

This helps us understand the context in which the communication is taking place. It can be very brief if there isn't much context to explain.

*You can include AI-generated text afterwards, but make sure it is clearly indicated as separate from your prose.*

Please also follow this rule when responding to comments from other humans, keeping your thoughts separate from the outputs of any prompts.

## Pull Request Prerequisite: Vouching

We use a vouch system to mitigate spam. If you would like to suggest changes to the codebase, please first:

1. [Open a discussion in the "Vouch Request"](https://github.com/prefix-dev/pixi/discussions/new?category=vouch-request) category describing what you want to change and why. Follow the template, keep it concise. Write in your own voice, don't have an AI write this.
2. A maintainer will comment `vouch` if approved.

If you aren't vouched, any pull requests you open will be automatically closed.

## Talk to Us Before Opening a Pull Request

1. Make sure you are vouched.
2. If there's no issue yet for the changes you would like to make, create one.
3. Contact maintainers on the issue or via [our Discord Server][discord] to indicate your willingness to contribute a pull request.
4. If a maintainer indicates that a pull request would be welcome, make your changes and submit the pull request according to the [template](./.github/pull_request_template.md).

## Implementing changes

See `pixi task list` for a list of tasks that can be helpful while implementing changes. Feel free to open a draft PR if you are unsure exactly what changes need to be made before the pull request is ready for review.
